# 维护与发布

发布资产：

- `hostip.sh`
- `host-router-linux-amd64`
- `host-router-linux-arm64`
- `host-router-source.tar.gz`
- `manifest.json`、`manifest.sig`
- `SHA256SUMS`

先编译并测试两个架构，将脚本里的版本和二进制 SHA256 更新为本次构建值，再生成源码压缩包。签名清单结构：

```json
{
  "version": "0.1.0",
  "assets": {
    "hostip.sh": {
      "sha256": "文件的完整SHA256",
      "url": "https://github.com/coexacx/host-router/releases/download/v0.1.0/hostip.sh"
    }
  }
}
```

清单需包含本次发布的脚本、两个二进制和源码包。签名对象是清单文件的原始字节，使用 Ed25519 私钥生成 64 字节的原始签名。不要在签名后再次格式化 JSON。

当前发布公钥（原始 32 字节十六进制）：

```text
6fdb995c777fe2483e1e74f4490046d339bf0a6a1c24c3193d8b85ca4bbe321d
```

私钥应独立保管，不上传 GitHub，不放在网站目录或源码包中。发布前使用当前版本的 `verify-release` 命令验证清单和每个资产条目，再用 `sha256sum` 验证资产本身。

使用草稿 Release 上传全部资产，校验完成后统一发布。不要在发布后原地替换同一个版本的二进制；修订应提升版本号并重新签名。
